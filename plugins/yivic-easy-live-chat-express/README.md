Yivic Easy Live Chat adds floating chat buttons for Zalo, Messenger and Phone to your WordPress site.

== Description ==

Yivic Easy Live Chat adds floating chat buttons for **Zalo** and **Facebook Messenger** to your WordPress site.

This makes it easy for your visitors to contact you through their preferred chat app.

You can enable or disable each chat option, customize phone numbers or IDs, and change display settings directly from  
**Settings → Yivic Easy Live Chat**.

= Features =

* Add Zalo chat button
* Add Messenger chat button
* Optional phone call button
* Simple and lightweight
* No tracking, no external dependencies
* Easy to configure

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/yivic-easy-live-chat-express`
2. Activate the plugin through the **Plugins** menu in WordPress
3. Go to **Settings → Yivic Easy Live Chat** and configure your Zalo / Messenger / Phone options

== Frequently Asked Questions ==

= Where will the chat button appear? =  
It displays as a floating widget on the left or right side of your site.

= Does this plugin add tracking code? =  
No. It does not include analytics, tracking, or third-party scripts.

= Does it work with all themes? =  
Yes, it works with any properly coded WordPress theme.
